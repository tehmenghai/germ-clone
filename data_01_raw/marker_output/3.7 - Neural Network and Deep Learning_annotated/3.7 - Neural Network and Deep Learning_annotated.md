## Remember Feature Engineering?

## •

## Feature engineering is the process of selecting, transforming, or creating the

## most relevant variables, known as “features”, from raw data to use in machine

## learning models.

## •

## For example, if you're building a weather prediction model, the raw data

## might include temperature, humidity, wind speed, and barometric pressure.

## •

## Feature engineering would involve determining which of these variables are

## most important for predicting the weather and possibly transforming them

## (e.g., converting temperature from Fahrenheit to Celsius) to make them more

## useful for the model.

## •

## In traditional machine learning, feature engineering is often a manual and

## time-consuming process that requires domain expertise. However, one of the

## advantages of deep learning is that it can automatically learn relevant

## features from the raw data, reducing the need for manual intervention.

## Sigmoid Activation Function
The sigmoid/logistic activation function is one of the most widely used functions:
•
It is commonly used for models where we have to predict the probability as
an output. Since probability of anything exists only between the range of 0
and 1, sigmoid is the right choice because of its range.
•
The function is diﬀerentiable and provides a smooth gradient, i.e., preventing
jumps in output values. This is represented by an S-shape of the sigmoid
activation function. A smooth gradient means the function has a continuous
and non-jumping slope across its domain. This is important for stable
learning. If a function had abrupt changes (jumps) in its output, the gradient
would be unpredictable, which would make training the model diﬃcult and
unstable.
•
The sigmoid function has a smooth and continuous gradient, meaning small
changes in the input will cause small changes in the output, which helps in
making gradual, consistent updates to the model weights during training.

## Backpropagation Training

## Backpropagation is the algorithm used for training neural networks, including MLPs.

## Forward Pass (Feed-Forward)

## The input data is passed through the

## network layer by layer until the output layer

## is reached.

## The output is then used to compute the loss

## function, which measures the diﬀerence

## between the network's prediction and the

## actual target values.

## A common choice for the loss function in

## classiﬁcation tasks is the cross-entropy loss.

## Backward Pass (Backpropagation)

## Gradients of the loss function with respect to

## the network's weights are computed using the

## chain rule of calculus, in a process known as

## gradient descent.

## Backpropagation allows neural networks to

## learn from their mistakes, adjusting the weights

## to improve performance on the training data.

## With the right adjustments over many iterations,

## the network can converge to a state where it

## makes accurate predictions on unseen data.

## Building a Neural Network (1/4)

## General Guidelines for Number of Layers

## •

## Shallow networks (1-2 hidden layers) are often

## enough for simpler datasets like MNIST, where

## the task is relatively straightforward.

## •

## Deeper networks (3-5 layers) are typically used

## for more complex datasets where hierarchical

## feature extraction is essential (e.g., in image

## classiﬁcation or speech recognition).

## •

## Very deep networks (6+ layers) can be useful for

## highly complex problems, but this often requires

## more data, more computation, and better

## regularization techniques (e.g., dropout, batch

## Building a Neural Network (2/4)

## General Guidelines for Number of Neurons per Layer

## •

## Start small: A good initial guess is to use 64, 128, or 256 neurons in the

## ﬁrst hidden layer.

## •

## Reduce neurons in subsequent layers: As the network learns more

## abstract representations, it’s common to reduce the number of neurons in

## subsequent layers (e.g., 256 → 128 → 64).

## •

## Scaling: For image classiﬁcation, you might start with 512 or 1024 neurons

## in the ﬁrst layer and then gradually reduce the number of neurons.

## •

## Keep the number of neurons balanced: If you have too few neurons, the

## model might be too simple to capture complex patterns. Too many

## neurons can cause overﬁtting and longer training times.

## Building a Neural Network (4/4)

## Monitor Model Performance and Adjust

## •

## Underﬁtting: If your model is not learning well or the training

## error is high, increase the number of neurons or add more

## layers to capture more complex patterns.

## •

## Overﬁtting: If your model is performing well on training data

## but poorly on validation/test data, you might have too many

## neurons or layers, causing the model to memorize the data.

## You can try:

## –

## Reducing the number of neurons or layers.

## –

## Using regularization techniques like dropout.

## –

## Using early stopping to avoid overﬁtting.
