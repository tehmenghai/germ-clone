## Supervised Learning

## Supervised Learning involves training a model on a set of input-output pairs .

## It learns a function that maps an input to an output based on example

## input-output pairs.

## Features & Labels:

## •

## Features are the input; Labels are the output.

## •

## Example: For an email spam detector, the email content is the feature,

## and the label is whether it's 'spam' or 'not spam'.

## Training Process:

## •

## A large dataset with labeled examples is provided.

## •

## The algorithm iteratively makes predictions ( predicted output ) on the

## training data and they are compared with the labels ( actual output ).

## Unsupervised Learning

## Unsupervised Learning involves training a model on a set of data without

## explicit instructions on what to look for. The goal is to identify patterns or

## structures in the data.

## Clustering & Dimensionality Reduction:

## •

## Clustering groups similar data points together.

## •

## Dimensionality Reduction reduces the number of random variables under

## consideration by obtaining a set of principal variables.

## Training Process:

## •

## The algorithm explores the data for patterns.

## •

## There's no 'correct answer' (labels) like in supervised learning.

## Reinforcement Learning

## Reinforcement Learning is about taking suitable actions to maximize

## reward in a particular situation. It's trained using trial and error .

## Agent, State, Reward:

## •

## Agent : The decision maker.

## •

## State : The current situation returned by the environment.

## •

## Reward : Feedback from the environment.

## Training Process:

## •

## The agent takes actions; the environment returns the new state

## and a reward.

## •

## The goal is to ﬁnd the best strategy, called policy , that will result

## in the maximum cumulative reward for the agent.

## Glossary

## Variable :

## An attribute that represents a dimension of the data. Variables can be used

## as input features for models, and they can also be the output or target that

## the model is trying to predict. Variables can be categorical or numerical.

## Feature :

## An individual measurable property or characteristic of a phenomenon

## being observed, often denoted as 'X' in models. Also known as input ,

## independent or predictor variable.

## Label :

## The variable we are predicting, often denoted as 'Y' in models. Also known

## as output , dependent or target variable.

## Algorithm :

## A set of rules or procedures that a machine learning system follows to

## perform a task.

## Model :

## The representation (internal model) learned by the machine learning

## algorithm.
